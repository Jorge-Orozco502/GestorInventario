# GestorInventario

Sistema de gestión de inventario diseñado para administrar productos, clientes, proveedores y ventas de una vidriería.

## Descripción del proyecto

**GestorInventario** es una aplicación desarrollada para facilitar el control y la administración de las operaciones de inventario de una vidriería.

El sistema permite organizar la información de los productos y gestionar las operaciones relacionadas con clientes, proveedores y ventas, manteniendo la información almacenada en una base de datos MySQL.

## Funcionalidades

- Gestión y administración de productos.
- Registro y administración de clientes.
- Registro y administración de proveedores.
- Gestión de ventas.
- Control de cantidades de productos.
- Consulta de información y reportes.
- Almacenamiento de información mediante MySQL.

## Tecnologías utilizadas

- Java.
- Maven.
- MySQL.
- MySQL Workbench.
- JDBC (si corresponde a la conexión utilizada por el proyecto).

## Base de datos

El proyecto utiliza MySQL para almacenar la información del sistema.

La base de datos del proyecto se denomina:

`inventario_vidrieria`

Los scripts SQL se encuentran en la carpeta `BaseDatos`.

## Instalación y ejecución

1. Clonar o descargar este repositorio.
2. Instalar Java y Maven.
3. Configurar el servidor MySQL.
4. Ejecutar el script SQL correspondiente para crear la base de datos.
5. Configurar los datos de conexión a MySQL en el proyecto.
6. Abrir el proyecto utilizando un IDE compatible con Maven.
7. Compilar y ejecutar la aplicación.
